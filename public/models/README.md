# 3B modeller

Bu klasör, lisanslı bir GLB/GLTF cihaz modeli teslim edildiğinde kullanılır.
Şu an site, `src/scripts/viewer/model.ts` içindeki **parametrik temsili** RIC modelini kullanır.

Gerçek model gereksinimleri: bkz. `src/scripts/viewer/README.md`
(parçalar ayrı mesh/gruplar olmalı ve şu adlarla adlandırılmalı: mics, body, button, wire, receiver, dome, power).
